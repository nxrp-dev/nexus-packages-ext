# PasZLib

Package identity: `NXRP.Compression.PasZLib`.

`external/paszlib` is an unchanged source snapshot of `packages/paszlib` from
`https://github.com/nxrp-dev/nexus-fpc.git`, revision `a7782c0f1291c1a7d6c90280a296a28e723b19f5`.
Only tracked source, metadata, examples and test fixtures are included; built units
and binaries are excluded. Original license notices remain in the sources and
readme; `COPYING.FPC` supplies the referenced FPC linking exception.

Add `external/paszlib/src` to the unit and include search paths. Matching RTL and
FPC `hash` units are required. Do not mix the same units from this snapshot and a
compiler distribution in one build. NexusFPC retains its own copy for bootstrap
and package ZIP creation; this package does not redirect the compiler build.
